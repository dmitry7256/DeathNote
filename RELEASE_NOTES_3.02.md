# Death Note 3.02 — Match Results & Lobby Simplification

### Изменения

- Быстрее обновляется счётчик матчей в Statistics после редактирования и удаления
- Добавлены карточки статистики по Completed, All players left, Restart, Game crashed, Unspecified / Other
- Убраны значки рядом с никами в лобби Civilization V — информация остаётся в подсказке при наведении
- Автоматическое начисление Win/Loss при Completed и выборе победителя
- В матче 1v1 при результате All players left сопернику автоматически начисляется один Quit
- Повторное редактирование, смена результата и удаление матча учитываются без двойных начислений благодаря учёту изменений по ID матча
- В окне редактирования матча и при послематчевом вводе результата добавлена подсказка об автоматическом начислении

### Обновление

1. Установите `DeathNote_Setup_3.02_x64.exe` или обновитесь через **Settings → Check for updates** после публикации установщика в GitHub Releases
2. Сохраните резервную копию базы через **Settings → Export database**, затем выполните **Check integrity**
3. Закройте Civilization V и запустите **Settings → Check modules → Repair / install** — прежние DDS-значки и XML-вставка будут удалены с резервными копиями
4. Перезапустите Civilization V и проверьте всплывающие подсказки в лобби

Личные данные игроков и история матчей остаются в `%LOCALAPPDATA%\DeathNote\data`

> Автоматические результаты действуют при изменении итога матча в этой версии. Старые вручную выставленные счётчики за исторические матчи не пересчитываются автоматически
